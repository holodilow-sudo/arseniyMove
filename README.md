# Arseniy Move

Репозиторий готовых Android-релизов приложения «Арсений — тренировки».

APK для установки находятся в [Releases](https://github.com/holodilow-sudo/arseniyMove/releases).

Устанавливайте новую версию поверх предыдущей. Не удаляйте приложение и не очищайте его данные: так сохраняются история тренировок, награды и настройки.

Для разработчика: публикуйте стабильный релиз с тегом `vX.Y.Z`, файлом `ArseniyMove-X.Y.Z.apk` и файлом `ArseniyMove-X.Y.Z.apk.sha256`. Новая версия должна иметь больший versionCode и прежнюю подпись.

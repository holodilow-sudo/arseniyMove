# Сборка Arseniy Move 1.0.14

Исходники соответствуют APK 1.0.14 (versionCode 15). Функции совпадают с 1.0.13, повышен номер версии. Автоматической отправки статистики нет. Обновления APK загружаются из публичного GitHub Releases без токенов на телефоне.

## Что входит

- `app/` — интерфейс, подсчёт упражнений, локальная модель MediaPipe, WASM, иллюстрации, видео и лицензии.
- `android/src/main/` — Android-оболочка, обновлятор, уведомления, голос, разрешения и обмен отчётом.
- `android/tools/` — помощник компиляции Java; `android/qa/` — исходники проверок.
- `scripts/` — сборка, проверка APK, локальный просмотр и тесты.
- `parent-dashboard/` — публичная страница графиков с пустыми реальными данными и отдельным демо. Синхронизация с телефоном не подключена.
- `docs/` — описание работы и происхождения ресурсов.

## Инструменты

Текущий скрипт сборки рассчитан на Windows. Нужны Python 3, JDK 17 и Android SDK Platform 35 + Build Tools 35. SDK и JDK установите из официальных источников; они не являются исходниками приложения и в архив не включены.

Укажите каталог инструментов переменной `MOVE_ANDROID_TOOLS`. В нём должны быть подпапки:

```
tools/
  jdk/          # один комплект JDK с java.exe, javac.exe, keytool.exe
  sdk-build/    # один комплект Build Tools: aapt.exe, aapt2.exe, zipalign.exe,
                # core-lambda-stubs.jar, lib/d8.jar, lib/apksigner.jar
  sdk-platform/ # один android.jar платформы 35
```

Из корня распакованного проекта в PowerShell:

```powershell
$env:MOVE_ANDROID_TOOLS = 'C:\AndroidTools'
python scripts/build-android.py
```

APK и SHA-256 появятся в `dist/`. Номер версии задаётся в `android/src/main/AndroidManifest.xml`. Для следующих релизов увеличивайте `versionName` и `versionCode`, обновляйте подписи версии в интерфейсе и параметры `scripts/verify-move-apk.py`.

## Подпись и совместимость

Приватная папка `android/.signing` хранится только у владельца приложения. Она намеренно исключена из архива и GitHub. Для обновления установленного приложения используйте **тот же ключ подписи**. В чистом проекте без предыдущих APK скрипт создаст новый локальный ключ; такой APK не сможет заменить установленный выпуск с другой подписью. Скрипт откажется собирать новую подпись при наличии предыдущих APK без их ключа.

Для независимой проверки положите прежний официальный APK 1.0.13 в `dist/`, затем выполните:

```powershell
python scripts/verify-move-apk.py
```

Эта проверка требует прежнюю подпись. Она сравнивает package, версии, сертификат, содержимое APK и разрешения.

## Локальный просмотр и проверки

```powershell
python scripts/serve.py
node scripts/test-state.mjs
node scripts/test-progress.mjs
node scripts/test-pose-engine.mjs
node scripts/test-voice-count.mjs
node scripts/parent-dashboard-test.mjs
```

Адрес просмотра печатает сервер. Демо работает только на localhost/127.0.0.1 с `?preview=1`, в отдельном хранилище. Исторические браузерные QA-скрипты содержат локальный путь к Playwright и требуют адаптации к вашей машине; они не нужны для сборки APK. Проверки физической камеры, уведомлений и установки выполняются на телефоне отдельно.

## Публикация обновления

В `holodilow-sudo/arseniyMove` создайте стабильный GitHub Release с тегом `vX.Y.Z`, APK `ArseniyMove-X.Y.Z.apk` и `ArseniyMove-X.Y.Z.apk.sha256`. Отметьте новый выпуск Latest. Не заменяйте опубликованный APK другой сборкой под тем же номером.

Приложение проверяет `/releases/latest` при открытии/возврате в меню, обычно раз в 6 часов. Кнопка в настройках запускает проверку сразу. Оно проверяет сумму, пакет, версию и сертификат; установку подтверждает пользователь. Полностью закрытое приложение обновления не проверяет.

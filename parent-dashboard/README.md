# Статистика Arseniy Move

Публичная страница с графиками: https://holodilow-sudo.github.io/arseniy-move-stats/

Страница читает `latest.json` из ветки `main`. Файл сейчас пустой: отправка с телефона ещё не подключена. Кнопка «Посмотреть пример» показывает только вымышленные данные в браузере, не меняя репозиторий.

## Формат данных

`schema: 1`, `timezone: "Asia/Chita"`, `uploadedAt: ISO-8601 или null`, `days: [...]`.
Каждый день: `day: YYYY-MM-DD`, `sets: количество сохранённых подходов`, `seconds: длительность вместе с паузами`, `unknownDuration: количество подходов без длительности`, `exercises: {pushup, squat, plank, pullup, boat, hang}`. Значения упражнений — повторы для pushup/squat/pullup, секунды для plank/boat/hang. Не складывайте повторы с секундами удержания.

Файл представляет всю доступную историю, по одной строке на день, без видео, токенов или личных сообщений. `uploadedAt` — время фактической успешной отправки, а не время просмотра страницы. Примеры не следует записывать в настоящий `latest.json`.

Сайт обновляет данные при открытии, по кнопке и раз в 5 минут пока вкладка открыта. Отключённый интернет не считается пропуском. До подключения телефона сайт не показывает вымышленные показатели как реальные.

Репозиторий публичный: опубликованный `latest.json` будет доступен всем. Для записи через GitHub API необходима авторизация. Ни ключей, ни секретов на этой странице нет. Подключение отправки — отдельный шаг; APK 1.0.13 статистику сюда не отправляет.

## Публикация

GitHub Pages: Deploy from a branch → main → /(root). Исходные файлы сайта размещены в корне. Достаточно статического хостинга, сборка и внешние библиотеки не нужны.
